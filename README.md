# StudentSuppliesOrderingSystem

IT415 Midterm Practical Examination - Student Supplies Ordering System

A browser-based ordering app for a small school supplies shop.

## Features
- Product list with 6 school supplies and prices
- Shopping cart with add, increase/decrease quantity, and remove
- Automatic subtotals and total amount
- Cash payment with validation (blank, invalid, negative, insufficient)
- Change computation
- Digital receipt with reference number, date/time, items, total, paid, change
- New Transaction button that resets everything

## How to run
1. Download or clone this repository.
2. Open `index.html` in any web browser. No installation needed.

## Files
- `index.html` - page structure
- `style.css` - styling
- `script.js` - cart, payment, and receipt logic
